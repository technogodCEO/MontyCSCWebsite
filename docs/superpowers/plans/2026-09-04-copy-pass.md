- [x] **Step 3:** `src/components/sections/WhyJoin.astro` — replace two of the three `reasons` bodies (reason 1's title/body and reason 3's title stay exactly as they are; only the body strings below change)

Current (`reasons` array, [WhyJoin.astro:12-21](src/components/sections/WhyJoin.astro#L12-L21)):
```javascript
const reasons = [
  {
    title: 'No experience required',
    body: 'Every workshop starts from the basics and builds up — whether it is your first line of code or your fifth language.',
  },
  {
    title: 'Trained instructors',
    body: 'Sessions are led by peers and mentors who know how to teach, not just how to code.',

  {
    title: 'A real community',
    body: 'Hackathons, guest talks, and competitions give you people to build with, not just a syllabus.',

```

Replace with:
```javascript
const reasons = [
  {
    title: 'No experience required',
    body: "Every workshop starts from the basics and builds up, so it doesn't matter if you've never coded or you already know five languages.",
  },
  {
    title: 'Trained instructors',
    body: "Sessions are led by peers and mentors who can actually teach. Coding well and teaching well aren't the same thing.",
  },
  {
    title: 'A real community',
    body: "Hackathons, guest talks, and competitions mean you're building with people, not just working through a syllabus alone.",
  },
];
```

Note the quote style: `.prettierrc.json` sets `singleQuote: true`, but Prettier switches to double quotes on a per-string basis when the string contains an apostrophe (to avoid escaping) — the reason-1 and reason-2 bodies above are written double-quoted for that reason (`doesn't`, `you've`, `aren't`). Reason 3's body has no apostrophe, so it stays single-quoted. Don't hand-pick quote style beyond this — write the strings as shown and let Step 6's `prettier --write` normalize anything off.
